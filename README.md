# Careflow Sim Lab

Отдельный браузерный учебный симулятор базового сестринского ухода для студентов медицинского колледжа. В MVP доступны полноэкранная 3D-палата с интерактивными объектами, данные пациента на стеновом экране и постоянная карточка текущего шага: следующие действия открываются последовательно после подтверждения или взаимодействия с нужным объектом. Для регулировки микроклимата доступен интерактивный термостат; значение 21 °C — только цель данного учебного сценария, а не универсальная медицинская норма. В палате есть окно с процедурной городской панорамой, которая меняет освещение по местному времени устройства и показывает актуальные часы; это не видеотрансляция из конкретного города. Размер пациента в сцене нормализован примерно до 1,8 м; одеяло соответствует размерам кровати. Камера от первого лица по умолчанию установлена на высоте 3,4 м (вдвое выше прежней настройки) и может быть откалибрована в панели настройки. Перемещение — WASD или стрелки, осмотр — мышью (с захватом курсора либо перетаскиванием).

Для калибровки сцены нажмите клавиши `Q`, `W`, `E` по очереди. В панели можно независимо настроить положение пациента и одеяла по трём осям относительно кушетки, масштаб пациента и одеяла, а также высоту камеры от пола для режима от первого лица. Настройки сохраняются в локальном хранилище браузера. Кнопка сброса возвращает исходные значения всех параметров сцены.

## Запуск

```bash
npm install
npm run dev
```

## Публикация на GitHub Pages

Публикация выполняется автоматически после отправки изменений в ветку `main`. Для локальной сборки укажите переменную `GITHUB_ACTIONS=true`, чтобы включить базовый путь Pages:

```bash
GITHUB_ACTIONS=true npm run build
```

Для production-сборки:

```bash
npm run build
npm run preview
```

## Технологии

- React + TypeScript + Vite
- Three.js через React Three Fiber и Drei
- Lucide для иконок

## 3D-модель палаты

Пока новая модель не создана, сцена использует [GRADD Hospital Room by GRADD CO](https://poly.pizza/m/9sUalfQ76kn) из `public/models/gradd-hospital-room.glb` как резервную. Автор и лицензия: [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). Требуемая атрибуция сохранена в `public/models/ATTRIBUTION.txt` и показана в интерфейсе в разделе «Источники и методика». После успешной генерации сцена автоматически выберет `public/models/hospital-room-generated.glb` при следующей загрузке.

Для генерации новой детализированной палаты через [Tripo3D H3.1 в GenAPI](https://gen-api.ru/model/tripo-3d) укажите действующий API-ключ в `nurse-care-sim/.env.local` (формат ключа из актуальной документации — `sk_...`), затем выполните:

```bash
npm run generate:room
```

Скрипт делает один платный запрос с PBR, HD-текстурами и детальной геометрией (ориентировочно 125 ₽ по опубликованным тарифам), ожидает результат, проверяет GLB v2 и сохраняет модель отдельно, не перезаписывая резервную палату. При ошибке или неподходящем результате старая модель остаётся в сцене. Никогда не храните реальный ключ в `.env.example`, исходном коде или чате.

Для создания модели пациентки используется [Tripo3D H3.1 в GenAPI](https://gen-api.ru/model/tripo-3d). Скопируйте `.env.example` в `.env.local` в корне `nurse-care-sim`, затем заполните `GEN_API_KEY` новым ключом, созданным в GenAPI. Идентификатор модели — `GEN_API_MODEL=tripo-3d`:

```bash
cp .env.example .env.local
# Откройте .env.local и вставьте новый API-ключ в GEN_API_KEY
npm run generate:patient
```

Либо укажите путь к уже существующему файлу окружения с `GEN_API_KEY`:

```bash
GEN_API_ENV_FILE=/absolute/path/to/.env npm run generate:patient
```

Также можно задать путь к уже существующему файлу окружения с `GEN_API_KEY` и `GEN_API_MODEL` через переменную `GEN_API_ENV_FILE`. `meshy-rigging` не является генератором модели по тексту: ему нужна готовая GLB, поэтому скрипт принимает для создания пациентки только `tripo-3d`.

Скрипт делает один платный запрос, ожидает результат, принимает только GLB v2 и сохраняет модель в `public/models/patient.glb`. GenAPI указывает стоимость от 25 до 100 ₽ в зависимости от параметров генерации; формат GLB заранее не гарантирован, поэтому неподходящий результат не заменит файл. Не добавляйте ключ в исходный код и не отправляйте его в чат. Если GLB ещё не создан, сцена сохраняет стилизованную модель-заглушку.

## Учебная методика и источники

Чек-лист — авторская учебная адаптация принципов безопасного ухода, не дословное воспроизведение клинических документов. В интерфейсе показаны ссылки на использованные первоисточники:

- WHO, [My 5 Moments for Hand Hygiene](https://www.who.int/publications/m/item/five-moments-for-hand-hygiene)
- WHO, [Guidelines on Hand Hygiene in Health Care](https://www.who.int/publications/i/item/9789241597906)
- NICE CG179, [Pressure ulcers: prevention and management](https://www.nice.org.uk/guidance/cg179)
- NICE NG249, [Falls: assessment and prevention](https://www.nice.org.uk/guidance/ng249)

Сценарий предназначен только для обучения. Он не заменяет локальные протоколы, назначения, клиническую оценку преподавателя или медицинского специалиста. Показатели пациента вымышлены. Не вводите в приложение данные реальных пациентов.

## Структура

- `src/App.tsx` — полноэкранный интерфейс симуляции, последовательность шагов и прогресс.
- `src/RoomScene.tsx` — 3D-палата, окно с панорамой по местному времени, стеновой экран пациента и интерактивные объекты.
- `src/scenario.ts` — учебный сценарий и ссылки на источники.
